# 任意方向の円柱状穴を3Dメッシュから検出する

Category: `enhancement`
Status: `needs-triage`

## 背景

PoCの2D円形度とレイヤー間連結は垂直穴に依存する。水平・傾斜穴は3D面から穴軸と内径を復元する必要がある。

## 期待する結果

メッシュの分割密度と穴軸の姿勢に過度に依存せず、円柱状の内壁を識別し、軸、中心、半径、軸方向の範囲、信頼度を返す。

## 受け入れ条件

- [ ] 垂直、水平、傾斜した円柱状穴で同じ検出I/Fを使う
- [ ] 軸、半径、長さを設定許容差内で復元する
- [ ] 径上限を超える穴を対象外にする
- [ ] 外周の円筒面や開いた円弧状の凹みを穴として確定しない
- [ ] メッシュ分割数が異なる同形状で結果が安定する
