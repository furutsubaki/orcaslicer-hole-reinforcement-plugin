# 任意方向の正多角形穴を3Dメッシュから検出する

Category: `enhancement`
Status: `completed`
Completed: `2026-08-20`

## 背景

多角形穴は円形度では安定に判定できない。六角・八角だけでなく、モデルで意図された正n角形やOrcaSlicerのpolyholeを扱うため、三角形化された平面群から断面辺数と穴軸を復元する必要がある。

## 期待する結果

設定された辺数範囲の正多角柱状内壁を識別し、辺数、軸、断面頂点、対辺寸法、軸方向の範囲、信頼度を返す。

## 受け入れ条件

- [x] 六角穴、八角穴、任意の正n角形を設定に応じて有効化できる
- [x] 辺長と内角の許容差を適用する
- [x] 穴の回転位相と軸方向に依存しない
- [x] 不規則な多角形と外周面を穴として確定しない
- [x] 三角形の分割方法が異なる同形状で結果が安定する

## Comments

隣接三角形の面法線から軸候補を求め、軸に平行な連結面を平面単位へまとめて断面を復元する`PolygonalHoleDetector`を追加した。六角・八角を固有形状として維持しつつ、3〜64辺の正多角形を設定範囲に応じて辺数付きで判定する。内向き法線、対辺寸法、辺長偏差、内角偏差、深さを検証し、軸姿勢、断面の回転位相、高さ方向の分割数、三角形の対角線方向が異なる場合も同じ候補I/Fを返す。円柱検出と同じ面を候補にした場合は統合I/Fで正多角形を優先する。OrcaSlicerのpolyhole変換は2Dレイヤー輪郭へ後から適用されるため、issue 10では実際のレイヤー輪郭を使って補強幅を確保する。
