# 貫通穴と止まり穴を分類する

Category: `enhancement`
Status: `completed`

## 背景

内壁の候補だけでは、穴がモデル外部へ開いているか、底面で閉じているか判定できない。補強範囲と誤検出防止のため穴端のトポロジーを調べる必要がある。

## 期待する結果

検出候補の両端を開口または閉塞として分類し、貫通穴、止まり穴、不確実な候補を判別する。

## 受け入れ条件

- [x] 両端が開口した候補を貫通穴と判定する
- [x] 一端が閉塞した候補を止まり穴と判定する
- [x] 局所的な凹み、スリット、壊れたメッシュを不確実として除外できる
- [x] 貫通穴と止まり穴の有効設定を個別に適用する
- [x] 分類理由を診断情報として取得できる
