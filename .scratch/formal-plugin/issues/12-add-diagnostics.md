# 検出と補強の診断情報を整備する

Category: `enhancement`
Status: `needs-triage`

## 背景

3D穴検出は形状許容差とメッシュ品質の影響を受ける。検出数だけでは、誤検出や検出漏れの原因を判断できない。

## 期待する結果

通常利用時は簡潔な実行結果を返し、診断有効時は候補の形状、寸法、軸、穴端分類、信頼度、除外理由、補強レイヤーを記録する。

## 受け入れ条件

- [ ] モデルとボリュームごとの検出結果を識別できる
- [ ] 採用した穴と除外した候補の理由を記録できる
- [ ] 補強したレイヤー数、Surface数、対象領域数を確認できる
- [ ] 診断無効時に大量のファイル出力を行わない
- [ ] 診断出力の書き込み失敗でスライス全体を失敗させない
