# 3D解析の実行時間とメモリ使用量を制御する

Category: `enhancement`
Status: `needs-triage`

## 背景

メッシュ全体の穴検出は、PoCの2D輪郭追跡より計算コストが大きい。高密度メッシュや複数インスタンスで通常のスライス操作を妨げない必要がある。

## 期待する結果

処理時間とメモリ使用量を計測し、正しさを変えない範囲で個別インスタンスの重複解析防止、早期除外、必要最小限のコピーを適用する。

## 受け入れ条件

- [ ] 代表的なメッシュ規模ごとに処理時間とメモリ使用量を計測できる
- [ ] 同一形状の複数インスタンスで不要な形状解析を繰り返さない
- [ ] キャッシュはモデル、変換、検出設定の変更で無効化される
- [ ] キャンセル要求を長時間無視する処理区間がない
- [ ] 最適化前後で検出結果と補強形状が一致する
