# Domain Docs

このリポジトリは単一コンテキスト構成です。

## 探索前に読む文書

- リポジトリルートの`CONTEXT.md`
- 検討対象に関係する`docs/adr/`配下のADR

文書がまだ存在しない場合はそのまま作業を続け、用語または設計判断が確定したときに作成します。

## 用語

issue名、設計案、仮説、テスト名には`CONTEXT.md`で定義した用語を使用します。未定義の概念が必要な場合は、既存用語の言い換えか、用語体系の不足かを確認します。

## ADRとの矛盾

作業内容が既存ADRと矛盾する場合は、暗黙に上書きせず、矛盾と見直し理由を明示します。
