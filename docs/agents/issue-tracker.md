# Issue tracker: Local Markdown

正式公開まで、このリポジトリのissueとPRDは`.scratch/`配下のMarkdownファイルで管理します。正式公開後はGitHub Issuesへ移行し、本文書の運用手順を更新します。

## 規約

- 1機能につき1ディレクトリとし、`.scratch/<feature-slug>/`へ保存する
- PRDは`.scratch/<feature-slug>/PRD.md`とする
- 実装issueは`.scratch/<feature-slug>/issues/<NN>-<slug>.md`とし、`01`から連番にする
- トリアージ状態はissue冒頭の`Status:`行に記録する
- カテゴリはissue冒頭の`Category:`行に`bug`または`enhancement`と記録する
- コメントと対話履歴は本文末尾の`## Comments`へ追記する
- AIが生成したissueまたはコメントは`> *This was generated by AI during triage.*`で始める

## skillからissue trackerへの公開を求められた場合

`.scratch/<feature-slug>/`配下へ新しいMarkdownファイルを作成します。必要なディレクトリも同時に作成します。

## skillから関連issueの取得を求められた場合

指定されたパスまたはissue番号に対応するファイルを読みます。
