# Issue tracker: GitHub Issues

このリポジトリのissueはGitHub Issuesで管理します。

正式公開前は`.scratch/`配下のローカルMarkdownで管理していました。それらは全件completeであり、実装・設計判断の根拠は`docs/`配下の各文書へ転記済みです。ローカルのissueファイル自体は残していません。

## 規約

- トリアージ状態はラベルで表す。定義は[`triage-labels.md`](triage-labels.md)を参照する
- カテゴリは`bug`または`enhancement`のラベルを付ける
- AIが生成したissueまたはコメントは`> *This was generated by AI during triage.*`で始める

## skillからissue trackerへの公開を求められた場合

`gh issue create`で起票します。ラベルは[`triage-labels.md`](triage-labels.md)の定義に従います。

## skillから関連issueの取得を求められた場合

`gh issue view <number>`または`gh issue list`で取得します。
