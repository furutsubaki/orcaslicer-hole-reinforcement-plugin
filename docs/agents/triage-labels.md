# Triage Labels

| 標準ロール | このプロジェクトの状態名 | 意味 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | メンテナーによる評価待ち |
| `needs-info` | `needs-info` | 追加情報待ち |
| `ready-for-agent` | `ready-for-agent` | AIエージェントが自律実装できる状態 |
| `ready-for-human` | `ready-for-human` | 人による実装や判断が必要な状態 |
| `wontfix` | `wontfix` | 対応しない |

トリアージ済みのissueには、`bug`または`enhancement`のカテゴリを1つと、上記の状態を1つだけ記録します。
