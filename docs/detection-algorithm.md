# 検出アルゴリズム

本書は、3Dメッシュから穴を識別する手順を記述します。何を穴とみなすかの判定基準は[`supported-hole-contract.md`](supported-hole-contract.md)、設定値の意味は[`configuration.md`](configuration.md)にあります。

2Dのレイヤー輪郭ではなく3Dメッシュを入力とするのは、輪郭ベースでは穴の向きに依存してしまうためです。水平穴や傾斜穴では、レイヤーを切った断面が穴の断面と一致しません。

## 入力メッシュ

`PrintObject.trafo() @ ModelVolume.matrix()`を適用した造形座標のスナップショットを使います。ミラーを含む変換では三角形の頂点順を補正して法線の向きを保ちます。複数インスタンス・複数ボリュームは、PrintObject・ModelObject・ModelVolumeのIDとvolume indexを値として保持して区別します（参照は保持しません。OrcaSlicerのホストオブジェクトの寿命を前提にできないためです）。

## 円柱状穴

1. 隣接三角形の面法線から軸候補を求める
2. 軸に平行な連結面群の頂点を、軸に直交する平面へ射影する
3. 射影点群へ**最小二乗で円を近似**し、中心と半径を得る
4. 次の4条件で候補を絞る

| 条件 | 除外されるもの |
| --- | --- |
| 法線が軸へ向かって内向きであること | 外周の円筒面（軸から外向き） |
| 断面の角度被覆が全周に達していること | 開いた円弧、溝 |
| 径と深さが設定範囲内であること | 対象外サイズの穴 |
| 半径偏差が`circle_radial_tolerance_mm`以内であること | 楕円穴、テーパー穴 |

メッシュの分割密度と穴軸の姿勢に依存しないよう、これらはすべて射影後の幾何量で判定します。

## 正多角形穴

軸候補の求め方は円柱状穴と同じです。軸に平行な連結面を**平面単位へまとめて断面を復元**します。

六角形と八角形は固有形状として扱い、それ以外は`min_polygon_sides`〜`max_polygon_sides`の範囲で辺数付きの正多角形として判定します。検証する量は、内向き法線、対辺寸法、辺長偏差（`polygon_edge_length_tolerance_percent`）、内角偏差（`polygon_angle_tolerance_deg`）、深さです。

軸の姿勢、断面の回転位相、高さ方向の分割数、三角形の対角線方向が異なっても、同じ候補を返します。

## 競合の解決

円柱検出と正多角形検出が**同じ面を候補にした場合は、正多角形を優先**します。辺数の多い正多角形は円へ近づくため円としても近似できてしまいますが、補強領域を対辺寸法から作るほうが角部の肉厚を確保できるためです。

## 穴端の分類

候補内壁の端にあるリム全周が、隣接する端面と多様体接続していることを必須とします。端面が穴軸上の断面中心を覆えば閉塞、覆わなければ開口とします。両端が開口なら貫通穴、一端だけなら止まり穴です。

分類結果には開始端と終了端の状態、穴端種別、採用可否、理由コードを含めます。

## 除外が診断に残らないケース

径と深さによる除外は、候補化する前に捨てるため`diagnostic.jsonl`へ理由が残りません。設定範囲外の穴が補強されない場合、診断を見ても何も出ていないのが正常です。[`troubleshooting.md`](troubleshooting.md)を参照してください。
