# 解析コストの計測

穴解析は、各モデルパートの頂点数・三角形数、処理時間、キャッシュ利用有無を`volume_detection_completed`診断イベントへ記録します。ピークメモリは計測自体の負荷を通常のスライスへ加えないよう、専用ベンチマークで計測します。

代表的な小・中・大メッシュは次のコマンドで計測できます。

```bash
PYTHONPATH=src python3 tools/benchmark_analysis.py
```

機械処理向けには`--json`を指定します。計測は同じ形状を平行移動した2インスタンスに対して実行し、検出数と検出形状が一致することも検証します。

キャッシュはメッシュ内容と全検出設定をキーにする最大32件、合計200万メッシュ要素のLRUです。モデル形状、回転、拡縮、検出設定が変わると再解析します。平行移動だけが異なるインスタンスでは解析結果を再配置して利用します。
